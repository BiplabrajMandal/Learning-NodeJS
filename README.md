# NodeJS Learning Portfolio 🟢

> A comprehensive collection of 8 NodeJS backend projects showcasing my progressive learning journey. Covers core fundamentals (Express Routing), advanced database integration (MongoDB, Mongoose), secure authentication (JWT, bcrypt), and API data validation. Built with robust MVC architecture and modern best practices to demonstrate my hands-on backend expertise.

## 🚀 What's Inside

This repository is meticulously organized into progressive topics, highlighting my understanding of the modern Node.js backend ecosystem.

### 🧩 Core Fundamentals (Parts 1-3)
- **Express Servers**: Understanding basic HTTP server setup, request/response cycles, and core Express mechanics.
- **Routing**: Designing RESTful API routes, handling URL parameters, and reading query strings.
- **Middleware**: Implementing standard and custom middleware to intercept and process incoming requests.

### 🗄️ Database Integration (Parts 4-5)
- **MongoDB & Mongoose**: Connecting applications to persistent MongoDB data stores using the Mongoose ODM.
- **Data Modeling**: Designing robust database schemas and defining relationships.
- **CRUD Operations**: Seamlessly creating, reading, updating, and deleting records in the database.

### 🔐 Security & Authentication (Part 7)
- **Password Hashing**: Securing plain-text passwords using `bcrypt` and strong salt rounds before database storage.
- **Stateless Auth**: Implementing secure login and registration workflows by generating and verifying JSON Web Tokens (JWT).
- **Session Protection**: Utilizing HTTP-only cookies and custom authentication middleware to protect private API routes.

### 📝 Validation & Error Handling (Part 8)
- **Data Integrity**: Integrating `express-validator` to aggressively sanitize and validate incoming request bodies (e.g., enforcing password strength).
- **Graceful Failures**: Implementing centralized error handling to prevent server crashes and return standardized JSON error messages to the client.

### 🛣️ Advanced Architecture (Part 6)
- **MVC Pattern**: Separating concerns across Models, Views, and Controllers for highly maintainable code.
- **Modular Routing**: Utilizing `express.Router` to build modular route handlers and avoid monolithic controller files.

## 🛠️ Tech Stack
- **Core Runtime & Framework**: Node.js, Express.js
- **Database Layer**: MongoDB, Mongoose (ODM)
- **Security Utilities**: JSON Web Tokens (JWT), bcrypt
- **Validation**: express-validator

## 💡 Why This Repository?
I created this repository to serve as a practical, real-world reference guide and to demonstrate my systematic approach to mastering modern backend engineering. Every folder represents a unique challenge solved and a new concept mastered, ensuring I write backend code that is secure, scalable, and highly maintainable.
